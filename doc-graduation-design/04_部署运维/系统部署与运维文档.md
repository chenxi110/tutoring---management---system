# 上课通 - 系统部署与运维文档

## 一、系统概述

**上课通 - 基于数据驱动的课外辅导教学辅助管理系统**

面向课外辅导机构的一站式教学管理平台，涵盖教学管理、家校协同、线上测评、数据分析四大核心能力。

### 技术栈
- **后端**：Spring Boot 3.2.0 + Java 17+ + MySQL 8.0
- **前端**：原生HTML/CSS/JavaScript单页应用 + ECharts 5.4.3
- **鉴权**：JWT Token + 角色权限控制
- **实时通信**：SSE (Server-Sent Events)
- **缓存**：Spring Cache + Caffeine
- **数据库连接**：Spring JDBC + HikariCP

### 系统角色
| 角色 | 权限范围 |
|------|---------|
| 超级管理员(admin) | 全部功能 + 操作日志 + 用户管理 + 系统配置 |
| 教师(teacher) | 所带班级教学管理 + 成绩 + 作业 + 家校沟通 + 上课模式 + 考试管理 |
| 家长(parent) | 查看自家孩子数据 + 收发私信 + 上课模式参与 + 请假申请 |
| 学生(student) | 我的成绩 + 我的作业 + 我的出勤 + 我的积分 + 上课模式参与 |

## 三、环境搭建

### 3.1 JDK安装配置
1. 下载JDK 17+（推荐Oracle JDK或OpenJDK）
2. 安装到指定目录（如 `F:\JAVA\jdk-17`）
3. 配置环境变量：
   - `JAVA_HOME` = JDK安装目录
   - `Path` 中添加 `%JAVA_HOME%\bin`
4. 验证：`java -version`

### 3.2 MySQL安装配置
1. 下载MySQL 8.0安装包
2. 安装时设置root密码（如 `123456`）
3. 启动MySQL服务：`net start MySQL80`
4. 创建数据库：
```sql
CREATE DATABASE skt_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
5. 导入初始数据（如有SQL脚本）

### 3.3 Maven安装配置（仅编译需要）
1. 下载Maven 3.6+
2. 配置环境变量 `MAVEN_HOME`
3. 配置 `settings.xml`（可选，配置国内镜像源）
4. 验证：`mvn -version`

## 四、系统部署

### 4.1 数据库配置
修改 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/skt_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
```

### 4.2 编译打包
```bash
# 进入项目目录
cd C:\Users\luoch\Desktop\上课通

# 编译打包（跳过测试）
mvn package -DskipTests

# 打包成功后，产物在 target/skt-server-1.0.0.jar
```

### 4.3 启动应用
```bash
# 方式一：直接启动
java -jar target\skt-server-1.0.0.jar

# 方式二：指定JVM参数启动
java -Xms128m -Xmx512m -jar target\skt-server-1.0.0.jar

# 方式三：使用启动脚本（Windows）
start-app.bat
```

### 4.4 访问系统
- 本机访问：`http://localhost:8081/tutoring-management.html`
- 局域网访问：`http://<本机IP>:8081/tutoring-management.html`

### 4.5 默认账号
| 角色 | 账号 | 密码 |
|------|------|------|
| 超级管理员 | admin | admin123 |
| 学生 | student01~student05 | admin123 |

> 注意：首次登录后请及时修改密码。

## 五、开机自启动配置

### 5.1 Windows启动文件夹方式
1. 创建启动脚本 `start-app.bat`：
```batch
@echo off
cd /d "C:\Users\luoch\Desktop\上课通"
start "" javaw -Xms128m -Xmx512m -jar target\skt-server-1.0.0.jar
```

2. 创建VBS脚本 `start-skt.vbs`（隐藏窗口启动）：
```vbscript
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "cmd /c C:\Users\luoch\Desktop\上课通\start-app.bat", 0, False
```

3. 将VBS脚本放入启动文件夹：
   - 路径：`C:\Users\<用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\`

### 5.2 Windows服务方式（推荐生产环境）
使用 `winsw` 或 `nssm` 将Java应用注册为Windows服务。

## 六、运维手册

### 6.1 日志查看
- 应用日志：控制台输出（或配置文件输出）
- 操作日志：数据库 `operation_logs` 表，可在系统"操作日志"页面查看

### 6.2 数据备份
```bash
# 备份数据库
mysqldump -u root -p123456 skt_db > backup_YYYYMMDD.sql

# 恢复数据库
mysql -u root -p123456 skt_db < backup_YYYYMMDD.sql
```

### 6.3 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 端口8081被占用 | 其他程序占用端口 | 修改application.yml中的端口，或停止占用程序 |
| 数据库连接失败 | MySQL未启动或配置错误 | 检查MySQL服务状态和连接配置 |
| 页面空白 | 前端资源加载失败 | 检查浏览器控制台，确认静态资源路径正确 |
| 登录失败 | 账号密码错误或用户不存在 | 检查users表数据，重置密码 |
| SSE连接失败 | 网络或代理问题 | 检查网络连接，确认无代理拦截 |

### 6.4 性能优化
- JVM参数：`-Xms128m -Xmx512m`（根据服务器内存调整）
- 数据库连接池：HikariCP，默认配置
- 缓存：Caffeine本地缓存，热点数据缓存10分钟
- 静态资源：Spring Boot默认静态资源映射
