# 课外辅导班教学辅助管理系统

## 简介

这是一个基于命令行的交互式教学管理程序,用于管理课外辅导班的班级、学生、上课记录、考勤统计和课时费等。

## 功能特点

### 核心功能
- **班级管理**: 支持多个班级(Python一级1/2/3班、图形化班等)
- **学生管理**: 每个班级独立的学生名单管理
- **上课记录**: 完整的上课记录增删改查
- **考勤管理**: 缺勤记录、学生缺勤总览、出勤率统计
- **课时统计**: 按月统计课时、按班级统计
- **课时费管理**: 设置单价、月度课时费统计
- **学期管理**: 创建和管理学期,按学期统计
- **数据导出**: 导出CSV文件、生成班级出勤报表

### 数据持久化
所有数据自动保存在本地JSON文件中:
- `students.json` - 学生名单
- `teaching_data.json` - 上课记录
- `config.json` - 配置信息(课时费单价、学期等)

## 使用方法

### 启动程序
```bash
python teaching_manager.py
```

### 主菜单功能

#### 记录管理 (1-5)
1. **添加上课记录** - 记录每次上课信息
2. **查看所有记录** - 按日期倒序显示
3. **修改记录** - 修改已有记录
4. **删除记录** - 删除错误记录
5. **按班级查看** - 筛选特定班级的记录

#### 学生管理 (6)
6. **学生名单管理** - 添加/删除/修改学生

#### 统计分析 (7-10)
7. **月度课时统计** - 统计某月的上课情况
8. **学生缺勤总览** - 查看某个学生的缺勤历史
9. **出勤率统计** - 计算学生出勤率
10. **月度课时费统计** - 计算月度收入

#### 学期管理 (11-12)
11. **学期管理** - 创建/删除学期
12. **学期统计** - 按学期统计数据

#### 数据导出 (13-14)
13. **导出为CSV** - 导出记录到Excel可读格式
14. **生成班级出勤报表** - 生成详细报表文件

#### 系统设置 (15)
15. **课时费单价管理** - 设置各课程单价

## 使用提示

### 添加上课记录
- 日期直接回车使用当天
- 节数默认1节
- 缺勤学生通过编号多选(如输入 1,3,5)
- 可手动添加不在名单中的学生

### 统计功能
- 可选择统计范围(仅正常课/包含补课等)
- 停课类型不计入统计
- 出勤率 = (应到节数 - 缺勤节数) / 应到节数 × 100%

### 数据备份
建议定期备份以下文件:
- students.json
- teaching_data.json
- config.json

## 系统要求
- Python 3.6+
- 无需安装第三方库(仅使用标准库)

## 注意事项
1. 所有输入都有格式校验,请按提示输入
2. 每次操作后数据自动保存
3. 日期格式统一为 YYYY-MM-DD
4. 月份格式统一为 YYYY-MM
5. 程序异常退出时数据已自动保存
